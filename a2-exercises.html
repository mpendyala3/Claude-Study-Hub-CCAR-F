CCAR-A2 Exercises · hands-on

Fourteen exercises, aimed at what you actually got wrong

Written to the Attempt-2 objectives and weighted deliberately: seven of these fourteen target objectives you scored 0% on, and the rest target the 50–67% tail. Nine are graded in your browser as you type; one is a terminal lab. The checklists name the exact properties the objective is written around, so a partial score tells you which property you missed.

Do these in order They are sequenced by priority, not by difficulty. Exercises 1–7 cover the zeros: review architecture, CI invocation, context: fork, tool distribution, tool_choice and sequencing, dynamic decomposition, and test generation. Exercises 8–13 cover the partial credits. Exercise 14 is a terminal lab that makes three of the zeros physical — if you only have an hour, do exercise 5 and then the lab.
Work them without the reference solution open Every exercise reveals a full worked answer, but the checklist is the teaching device: it names each requirement the exam grades on. Get to a partial score first, read which checks failed, and fix them — that loop is what transfers to exam day. Your editor contents are saved locally in this browser, so you can come back to a half-finished answer.

Browser-graded

Write JSON or code into the editor and hit Check. Each check is a requirement the exam actually tests, phrased so a failure tells you what to change.

Classification drills

Fast recall for the decisions the exam repeats: which config surface, which hook event, which intervention, escalate or not.

Terminal labs

Run against a real Claude Code install. Deliberately break things — wrong exit code, wrong matcher, missing -p — and watch the failure mode.
